# 🐍 Snake Game

A simple and fun classic Snake Game built using **HTML, CSS, and JavaScript**.

Control the snake using your keyboard, eat food to grow longer, and try to achieve the highest score without hitting the walls or yourself!

## 🎮 Features

- Classic Snake gameplay
- Keyboard arrow controls
- Dynamic food generation
- Score tracking system
- Snake grows after eating food
- Wall and self-collision detection
- Game Over screen
- Restart game functionality
- Simple and clean dark-themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## 🕹️ How to Play

1. Open `index.html` in your web browser.
2. Use the arrow keys to control the snake.
3. Eat the red food to increase your score.
4. Avoid hitting the walls or your own body.
5. Click the Restart Game button to play again.

## 🎯 Controls

| Key | Action |
|---|---|
| ⬆️ Arrow Up | Move Up |
| ⬇️ Arrow Down | Move Down |
| ⬅️ Arrow Left | Move Left |
| ➡️ Arrow Right | Move Right |

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/snake-game.git
```

Open the project folder and run `index.html` in your browser.
